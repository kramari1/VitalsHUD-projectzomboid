# Vitals HUD

Vitals HUD is a compact and customizable survivor status display for **Project Zomboid Build 42**.

The mod provides continuous feedback for things your survivor could reasonably feel or perceive, while keeping hidden game-state information optional.

## Features

### Always Visible

- Health
- Endurance
- Fatigue
- Hunger
- Thirst
- Core body temperature gauge

Core body temperature is shown as a **cold / normal / hot** gauge by default rather than as an exact number.

### Conditions

Additional conditions appear automatically only when active:

- Pain
- Stress
- Panic
- Sickness
- Food Sickness
- Wetness
- Discomfort
- Unhappiness
- Boredom
- Intoxication
- Poison

When a condition returns to zero, it disappears from the HUD again.

## HUD Customization

Drag the `::` handle to move the HUD.

The selected position is remembered between sessions.

Right-click the `::` handle to open the options menu.

Available options include:

- Small, Normal and Large HUD sizes
- Bar or numeric stat displays
- Optional hidden-information settings

## Hidden Information

Hidden information is **disabled by default** to preserve the intended immersive experience.

From **Hidden values (ruins immersion)**, players can optionally enable:

- Exact body temperature
- Zombie infection status
- Calories

## Display Only

Vitals HUD does not modify character stats, survival mechanics, or gameplay difficulty.

It only displays information.
