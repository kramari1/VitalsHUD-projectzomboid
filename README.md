# Vitals HUD

Vitals HUD is a compact, expandable status display for **Project Zomboid Build 42**.

It provides continuous feedback for stats your survivor should reasonably be able to feel or perceive, without exposing hidden information such as zombie infection.

## Features

- Health
- Endurance
- Fatigue
- Hunger
- Thirst
- Expandable detailed status view
- Pain
- Stress
- Panic
- Sickness
- Food Sickness
- Wetness
- Discomfort
- Unhappiness
- Boredom
- Intoxication
- Poison
- Core body temperature gauge
- Secondary conditions automatically hidden when inactive
- Automatically hides while hovering vanilla moodles
- Display-only; does not modify gameplay or character stats
- Does not reveal zombie infection status
